# Customer Shopping Behavior Analysis(End to End)

## Project Overview

This project performs an end-to-end analysis of customer shopping behavior using transactional data from **3,900 purchases**. The objective is to identify purchasing trends, customer segments, revenue drivers, and actionable business insights through Python, SQL, PostgreSQL, and Power BI.

---

## Business Problem

A retail company wants to understand customer purchasing behavior to improve customer engagement, increase revenue, and optimize marketing strategies using data-driven insights.

## Project Workflow

### 1. Data Cleaning & Preparation

* Imported dataset using Pandas
* Performed exploratory data analysis
* Handled missing values
* Standardized column names
* Created new business features
* Loaded cleaned dataset into PostgreSQL

### 2. SQL Business Analysis

Solved multiple business scenarios including:

* Revenue by Gender
* High Spending Discount Users
* Top Rated Products
* Shipping Preference Analysis
* Subscription vs Non-Subscription Analysis
* Customer Segmentation
* Revenue by Age Groups
* Top Products by Category
* Repeat Purchase Analysis

### 3. Power BI Dashboard

Interactive dashboard containing:

* Revenue KPIs
* Customer Segmentation
* Subscription Analysis
* Product Performance
* Shipping Insights
* Purchase Trends

---

## Key Insights

* Subscribers generate significantly higher revenue.
* Express shipping customers spend more on average.
* Female customers contribute slightly higher revenue.
* Loyal customers create the highest lifetime value.
* Highly rated products should receive greater marketing focus.
